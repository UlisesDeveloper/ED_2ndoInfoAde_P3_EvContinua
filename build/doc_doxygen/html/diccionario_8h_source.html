139 Because :: is used to access static variables, functions, and inner types alike,
140 the compiler needs to know which one you are grabbing. Whenever <T> or <T, U> appears to the left of ::,
141 the compiler can't look inside that template yet to check for itself,
142 so typename explicitly tells it: "What comes after :: is a datatype, not a variable or a function."

144
145 typename is not a one-time declaration at the top of a class (that's what template <class T, class U> does)—it is a tag you have to stick directly onto every single line where you write SomethingWithT<T, U>::InnerType
